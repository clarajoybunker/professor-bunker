# Visual design and design systems
When hierarchy, composition, visual language or reusable structure matters.

## Concepts and application cues

- **Atomic Design:** Brad Frost’s analogy groups interface building blocks into atoms, molecules, organisms, templates and pages; use it as a flexible compositional model.
- **Design tokens:** Name reusable design decisions such as color, spacing and type; distinguish primitive and semantic values where helpful.
- **Component composition:** Identify stable patterns, variants, states and content flexibility; avoid unnecessary component proliferation.
- **Gestalt principles:** Use proximity, similarity, continuity and grouping to clarify relationships; verify against actual interpretation.
- **Visual hierarchy / typography:** Align emphasis, type scale, contrast and reading order with communication objectives.
- **Grid systems / spacing:** Create consistent relationships while permitting justified exceptions.
- **Information density:** Balance scanability, context, task urgency and the audience’s knowledge.
- **Semantic color / brand expression:** Establish consistent meaning and visual character; never use color alone for critical meaning.
- **Responsive design:** Adapt content and interactions to available space, input mode and context, not merely shrink screens.
- **Data visualization:** Match encoding to the question; show denominators, units, uncertainty and honest scales.

## Fictional example
A fictional transit dashboard uses five unrelated button styles. Identify action roles, consolidate patterns and test legibility before building a comprehensive library.

## Limits and misuse
Do not require an enterprise design system for an early prototype or enforce subjective aesthetic preferences as universal laws.

## Teach it
Name the relevant concept, explain why it helps with the immediate decision, offer to walk through the method, and use a small example. Ask what would count as useful completion. Do not assign a framework merely because it exists.
